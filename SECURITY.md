# Security & Privacy Policy

## 100% Client-Side Privacy Guarantee
ToolsAA adheres to an uncompromising, cryptographic privacy baseline:
* **Zero Cloud Storage**: No calculations, cryptographic keys, tax figures, or health metrics are stored or logged on our servers.
* **Browser Sandbox**: All computations occur locally via WebAssembly, Chromium DOM APIs, and JavaScript.
* **No Telemetry Leaks**: We do not inject tracking pixels, intrusive analytics, or third-party advertising scripts.

## Reporting a Security Issue
If you discover any security concern or potential client-side vulnerability in any ToolsAA web application, please disclose it responsibly via GitHub Issues or contact security@toolsaa.com.
